mvcprogrammer.com

The tech behind this site, in four editions

The default edition of this site follows the KISS principle: keep it simple, and add nothing that is not earning its place. Plain HTML, CSS, and JavaScript with no framework, no build step, and no dependencies. The files live in a private S3 bucket that only CloudFront can read through Origin Access Control. CloudFront serves them worldwide over HTTPS with an ACM certificate, Route 53 points the domain at the distribution, and a GitHub Actions workflow authenticated with OIDC syncs the bucket and invalidates the cache on every push to main. No servers, no load balancer, no auto scaling group.

The Experience section is also served by a C# API on Lambda and DynamoDB, with default HTML as a fallback.

You are reading the third edition: the same page rebuilt as an Angular 22 app, TypeScript and signals in the browser, served the same way from an angular/ prefix of the same bucket. The second and fourth editions do it again in Blazor WebAssembly and in React. The JavaScript, Angular, React, and Blazor chips under Core skills are links; each one switches to the edition built on that stack. The colophon at the bottom has the details.

Interactive Property Search Window Display

Touch screen kiosk, React + .NET on AWS

A touch-screen kiosk behind the window of a Clearwater Beach real estate office, running since 2010. Visitors pick sales or rentals over an aerial photo of Sand Key, browse live Stellar MLS listings and photos pulled through the Bridge Data Output API, and ask to be emailed details or called back from an on-screen keyboard. The 2026 rebuild is a React and TypeScript screen built with Vite, pixel-matched to the original against captures of the live kiosk, in front of a .NET 10 API on AWS Lambda served through CloudFront.

Built for 1920×1080. The screen is pixel-matched to the kiosk's fixed full-HD display and runs full screen at that resolution. In any other window it scales itself to fit, letterboxed, so the live demo below looks like the kiosk on a laptop or a phone.

lightsplitters.com

Photography studio, Angular on AWS

The website for LightSplitters Media, a Tampa Bay photography studio I have a vested interest in: weddings, portraits, family albums, and archival prints. An Angular 22 workspace with standalone components and signals, prerendered to static HTML with no server. A second app in the same workspace is a template for client sites, so each couple's wedding site or family album lives at its own subdomain from one shared build plus a JSON file and a folder of photos. Masonry galleries with a native dialog lightbox, responsive WebP and JPEG images, a contact form that posts to a Lambda function sending through SES, and print orders through Stripe Payment Links. All of it served from a private S3 bucket through CloudFront, with a CloudFront Function routing each subdomain to its folder.
