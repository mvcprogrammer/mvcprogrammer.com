About Me

I've spent 15+ years building enterprise API applications on C# / .NET and SQL Server, with Angular front ends over ASP.NET Core Web APIs. My SQL Server work runs deep: complex queries, stored procedures, indexing, execution plan analysis, and performance tuning under concurrent load.

Most recently I re-architected a legacy interval-polling Windows service into an event-driven RabbitMQ pipeline that handles 1M+ API requests around the clock. Before that I developed and maintained TOPS Software's proprietary accounting system, covering general ledger, receivables, payables, bank reconciliation, and financial reporting.

I build on SOLID principles and modern software engineering patterns, and I own my work end to end, from Sprint 0 and architecture review through delivery, code review, mentoring, and production root-cause analysis. Teams count on me to ship on schedule and to leave the codebase better than I found it. AI-assisted tools like Claude Code are part of my daily workflow.
