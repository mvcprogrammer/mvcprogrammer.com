About Me

I've spent 15+ years building enterprise API applications on C# / .NET and SQL Server, with Angular front ends over ASP.NET Core Web APIs. My SQL Server work runs deep: complex queries, stored procedures, indexing, execution plan analysis, and performance tuning under concurrent load.

Most recently I spent two years on the AI Transition Team at an enterprise healthcare software company, bringing GitHub Copilot and then Claude into day-to-day development and learning, from production code and code-review feedback, what makes an AI pair programmer worth trusting. I have since put those lessons into my own Claude skills and agents, written from my experience in the healthcare and accounting fields: HL7 v2 and FHIR interoperability skills, accounting-domain skills, and reviewer agents that enforce my coding standard. The result is a pair programmer that already knows the domain and my production patterns, so useful work starts on day one, as the HL7 and FHIR projects on this site show. The skills and agents live in a private repository of mine and are available for viewing on request.

I build on SOLID principles and modern software engineering patterns, and I own my work end to end, from Sprint 0 and architecture review through delivery, code review, mentoring, and production root-cause analysis. Teams count on me to ship on schedule and to leave the codebase better than I found it.
